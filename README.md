# 🐍 Mis Proyectos de Python — Curso desde Cero

Repositorio con los proyectos prácticos desarrollados durante el curso.

## 📂 Proyectos Incluidos Semana 2

### 🎮 Proyecto 1: Juego Adivina la Palabra 
- **Descripción:** Juego interactivo tipo ahorcado sobre conceptos de programación.
- **Conceptos:** Bucles `while`, condicionales `if/else`, listas, conjuntos (`set`) y formateo de cadenas.

### 🛒 Proyecto 2: Sistema de Inventario y Ventas Mini-POS 
- **Descripción:** Sistema interactivo de terminal para gestión de almacén, carrito de compras y emisión de facturas.
- **Conceptos:** Diccionarios anidados, tuplas inmutables (`CONFIG_TIENDA`), listas dinámicas, control estricto de stock, formateo financiero (`:.2f`) y cálculo de IVA.
